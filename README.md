# AuthorityManager – Role-Based Permission Control
AuthorityManager provides secure access control for smart contracts by managing privileged roles, administrators, and delegated operational rights.

## Core Capabilities
- Assign and revoke authorized roles
- Multi-admin governance model
- Permissioned function execution enforcement
- On-chain audit trail of authorization changes

## Key Functions
grant-role, revoke-role, has-role, get-admin, set-admin
